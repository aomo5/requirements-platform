# 交互模式

## canvas · 画布与属性

页面、流程和状态是用户工作的对象。画布负责全局关系、选择和对比；右侧负责选中对象的操作；导航负责需求和产物定位。

### 对象行为

- 单击选择，并同步右侧属性；“页面预览”和“元素关联”放在属性区顶部，避免双击意外进入运行模式。路由、源码等低频设置按需展开。
- 页面名称旁披露控件展开真实状态画板。收起恢复原缩放、视口和选择。
- 页面状态保持正式 pageId + state route 关联身份；派生画板不重复保存为正式页面。
- 平移快捷键只在画布适用；不能抢占输入或按钮的 Space/Enter 行为。

### 画布反馈与连续手势

- 悬停边框为 1px、选中框为 2px，均按屏幕像素计量；缩放不改变粗细，选中不改变标题字重。尺寸标注保持可读大小，低于 20% 时隐去，避免密集视图被标签占满。
- 分组装饰在画板下层，拖动对象临时提升显示层级。分组标题与其他画板重叠时完整隐去，空间足够后恢复；不挪动真实画板来修复界面装饰的重叠。
- 吸附参考视野附近的画板及共同选择范围的边缘/中心。吸附范围 6 个屏幕像素，已吸附目标到 9px 才释放，减少目标跳动；跨轴远离的对象不吸附，低于 10% 时暂停吸附。Alt 按下/释放即时重算。
- 辅助线保持 1px，仅连接实际对齐对象，端点各留 8px 并显示短刻度；整数坐标不显示无法成立的半像素对齐，坐标边界阻止对齐时不显示误导参考线。
- 拖动期间只更新临时显示，松手才提交位置；一次有效移动只占一步撤销。Esc、失焦、页面隐藏或指针捕获丢失取消本次手势并清理反馈，不把半途坐标写入自动保存。
- 框选、画板拖动及视口移动按动画帧合并更新；移动只重算相关分组，选中集合不变时不重绘属性区。导航期间不闪现途经对象的悬停框。
- 缩放保持鼠标下的画布点不动；滚轮/触控板统一像素、行和页单位，Shift 纵向滚轮用于水平平移。缩放增量限制突跳，按钮缩放保持视口中心；平移不改变选择。

以上为工作台校准规则，不将固定数值宣称为 Figma 的精确内部参数。

### 页面说明与设计

页面目录、画板、说明与关联共用一个设计对象。右侧显示当前页说明摘要并提供查看／编辑入口，跨页约定放设计总说明；多状态共用说明时展示真实来源并编辑同一份内容。尚无画板时标明待设计，后续补图沿用 ID，不提供空白业务预览。说明与画板一起保存、撤销和处理版本冲突；失败保留输入。旧页面文档只在设计版本记录读取，旧入口定位承接对象，不保留第二套可编辑模块。

### 可选流程

需求可以没有流程。独立流程、补充流程和跨需求引用表达不同关系；引用保留来源，不复制为一份无来源流程。从节点进入页面后应返回原节点和视口。

浏览返回与流程业务关系分开呈现：返回上次查看位置仅记录本次跳转的来源和目标范围，切换无关流程或需求后清理；选择节点后同步刷新，并核验来源仍存在。不能以“跨图出口”称呼浏览历史，让它看似当前节点的业务出口。节点承接、调用返回和独立恢复继续按各自结构化关系显示。

### 流程节点属性的阅读与编辑

- 所选节点和连线默认按阅读态呈现名称、属性及说明；点击“编辑”再显示表单与增删操作，点击“完成”返回阅读。进入编辑后继续自动保存；未完成输入或保存失败保留草稿并提供明确恢复入口，不能因退出模式或切换节点丢失。
- 流程属性区用“基础属性／参数契约”页签区分原有属性与新增参数：基础属性保留原设置和说明，参数契约同时列出输入、返回及来源承接，不把输入和返回再拆成页签。采用 Figma 编辑器方向的紧凑中性灰选中态与同源 token。页签只影响显示，复制、CLI 与保存仍包含两组完整参数；支持左右方向键及 Home/End，切换节点恢复阅读态。
- 流程属性面板支持收起／展开和边缘拖动调宽；收起后保留可见展开入口，恢复原宽度、当前页签和草稿。宽度与收起状态作为本机界面偏好记忆，不写入流程模型；调宽为画布保留可用空间，支持键盘微调、双击恢复默认和 Esc 取消拖动。
- 基础属性中的长说明显示摘要，点击“查看全文”打开只读弹窗。参数契约的输入和返回表默认只列字段名、类型、必需性；直接点击任一行或用键盘激活字段名查看完整来源、条件和含义，不另设详情文字按钮。完整内容保留，查看不产生保存；只有明确点击“编辑”才进入表单，按实际权限显示编辑入口，关闭后恢复焦点。

### 流程排布与连线

- 沿用节点/连线结构与 Mermaid 源码互通。自动排布用于新导入节点或显式改变流程方向；打开流程、改文字或关联页面不重排已保存坐标。回路只在排布计算中识别，不能删除实际回边、重建节点编号或解除页面/需求关联。
- 主路径按层推进，分支按节点真实尺寸留白，汇合居中；同一层保持稳定顺序，独立分支之间留出更大间隔。新增节点按流程方向接续并对齐中心，不用不同形状的左上角代替视觉对齐。
- 连线从形状边界进出，按用户确认恢复平滑曲线；自环和并行路径分别计算。连线文字贴近曲线中点，使用画布同色保护底，不显示白色标签框，不自动移到远离连线的位置。可读空间不足时保留完整标题和属性值，不截断实际存储内容。
- 节点与连线的选中/悬停描边保持屏幕像素；连线命中区独立于可见线宽。拖动使用临时位置及共享吸附规则，一次松手提交一步撤销；移动中保留节点 DOM、焦点和页面关联。
- 适应全部同时计算节点、绕行连线和标签范围，并为顶部上下文及底部工具栏留白。平移不清选择；进入关联页面的返回参数必须跟随最新视口。

### 流程文字与箭头

- 节点标题按实际字体宽度、形状内部空间和页面标记留白换行；中文标点不轻易落到行首，英文单词与组合字符尽量保持完整。保留显式换行，居中多行标题在可容纳原文时均衡行宽，避免末行孤字。
- 固定节点尺寸内放不下时明确省略，完整原文仍在悬停标题、无障碍名称和属性中；显示调整不扩张节点、不改写原文、不移动已保存坐标。页面标记与正文分别占位。
- 连线标签最多显示三行，保护底与点击区域采用同一套测量结果；拖动时跟随曲线中点。优先保持文字和所属连线的视觉对应，避免浮动标签让分支含义难以判断。
- 文本保持矢量渲染与稳定字号、行距，不随缩放反复换行；低倍用于看结构，细读时放大。箭头尖端对齐节点边界，缩放尺寸有界，选中与悬停沿用连线颜色。主画布、Mermaid 预览和 SVG 导出共用文字排版与箭头锚点。


## links · 需求与元素关联

关系由需求段落、页面、页面状态和元素共同确定。备注属于这个关联，不能只用屏幕坐标记录。

### 从需求到元素

点击需求段落的关联入口，先显示已有元素；选择已有元素时打开对应页面和状态、定位目标，不进入新增选取。新增关联才展开页面选择并进入一次点选模式；没有关联时直接提供页面选择。已有元素显示真实状态名，不使用“页面状态”占位。

### 从元素回到需求

元素面板展示真实需求依据与备注。回到原文后定位原段落并恢复关联入口的键盘焦点；再进入已有元素时保留其状态。多条依据不覆盖，允许分别解除。

### 备注与状态

备注自动保存；切换状态、选择另一关联或离开前保存有效修改。失败保留当前任务。只选中目标、尚无内容的新草稿允许直接取消。

状态选择就在关联面板内。切换时保留待关联需求；点击其他状态的关联项自动切换并定位。选取模式提示只在模式期间出现，普通阅读不常驻教程。选中项自动进入列表可见范围；列表与编辑区分别滚动，长列表不能挤走备注输入。选取元素或添加依据后焦点进入备注；Esc 先收起依据选择器，再关闭外层。

### 失配处理

目标已删除、结构变化或原文失效时保留记录并说明待核对；提供重绑或重新选择入口。不能猜测替代目标，也不能静默删除需求依据。

验收使用一条真实链：原文 → 已有元素 → 改备注 → 切换状态 → 定位另一元素 → 返回原文。测试保存、位置、焦点和内容，不只看能否打开页面。

## creation · 新建与原位编辑

可逆的空白页面和独立流程点击即创建，使用不冲突的默认名称，选中并定位。名称在列表内编辑；尺寸和其他属性创建后调整。

### 命名

F2 或明确重命名入口进入编辑；Enter 确认，Esc 恢复，失焦保存有效值。空名恢复原值或给出贴近字段的校验。中文组合输入未完成时不得误提交。

### 延续当前工作

从节点创建补充流程时携带父流程和父节点。导入页面从现有原型选择；不再要求重复填写已有名称与尺寸。连续创建保持新对象可见，可撤销。

## states · 状态完整性

状态清单是可直达的真实内容，不用重复默认页充数。每个声明状态都有稳定 ID、名称、路由、必要尺寸和触发条件。

| 维度 | 按实际业务判断适用项 |
| --- | --- |
| 业务 | 不同订单、审核、支付或任务状态造成的字段和操作变化 |
| 数据 | 正常、加载、首次空、搜索空、缺失数据、加载失败 |
| 表单 | 初始、已填、依赖变化、校验、提交中、失败保留、成功、冲突 |
| 选择器 | 未选、已选、搜索无结果、前置未满足、占用禁选 |
| 弹窗 | 真实内容、取消、确认、校验、失败恢复 |
| 权限 | 只读、无权限、权限失效 |

### 展开质量

每张画板保留真实字体、组件和内容尺寸。长表单和弹窗底部可见或可达；总览后可原尺寸预览。只有影响可见内容或后续行为的状态才单独展开，避免无差异组合。

交互示例用本地演示数据。业务状态、接口口径和权限以项目规格为准，不为了视觉完整臆造业务。
