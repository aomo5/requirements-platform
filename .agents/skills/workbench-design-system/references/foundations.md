# 基础

## overview · 设计原则

工作台设计系统 1.0 · 2026-10-16。面向需求阅读、流程编排、页面设计和元素关联。默认浅色主题。

Ant Design 提供规范组织的参考；Figma 编辑器提供视觉和交互的参考；中文阅读、现有业务与用户反馈决定本系统的具体取舍。

### 内容优先

当前需求、流程或页面占据视觉中心。导航负责定位，属性区负责当前对象的操作。嵌入工作区不重复顶栏；控件数量随选中对象变化。

### 直接操作

可逆的新建立即完成，名称就地编辑。选择先有反馈，修改自动保存。用户不必先经过命名弹窗、说明页或确认步骤才能开始。

### 上下文连续

从需求到页面元素，再到状态、备注和原文，始终保留同一个任务上下文。来源、选择和输入都属于操作的一部分。

### 克制而明确

低频信息按需出现，高频操作保持可见。界面精简不等于把必要值藏在图标或悬停提示里。只凭颜色和图标难以判断的内容，保留短标签。

### 一套规则，分清适用端

12px 工具文字适用于密集桌面工作台；长文阅读用 14px，业务移动表单沿用业务端字号与触控尺寸。应用规范前先确认所在层级。

## color · 色彩

色彩分为基础色板、语义角色、组件状态三层。实现引用 `--wb-text-primary` 等用途明确的变量，组件不自行挑相近灰色。

### 中性色与文字

| 角色 | token | 用途 |
| --- | --- | --- |
| 主文字 | text-primary | 正文、输入值、选中对象名称 |
| 次级文字 | text-secondary | 标签、非选中导航、时间与属性名 |
| 辅助文字 | text-tertiary | 简短计数、尺寸、非关键提示；不能承载唯一业务规则 |
| 禁用文字 | text-disabled | 真实不可用控件，仍保留必要的原因入口 |
| 表面 | bg-surface / bg-subtle | 面板与次级表面 |
| 画布 | bg-canvas | 让页面、流程节点从工作区域中分离 |
| 分隔 | border / border-control | 分组边界与控件轮廓，不能互相代用 |

主文字沿用用户确认的 #383838，常规字重 400；次级 #707070。白底辅助文字 #767676，灰底必要文字改用次级或主文字。禁用色不叠加整体 opacity。

### 强调与语义

Figma 官方公开的品牌蓝 #0d99ff 用于选框、标记和强调边界；小字号白字主按钮使用更深的 #0768cf，文字链接也用该深蓝。成功、警告、错误同时配文字或图标，不能仅靠颜色判断。

| 情境 | 使用 | 避免 |
| --- | --- | --- |
| 当前对象 | 浅选中底、名称 500、必要选框 | 所有名称都变蓝加粗 |
| 输入焦点 | 2px focus 外轮廓 | 用整页主色强调当前字段 |
| 失败 | 错误文本、相关字段和重试动作 | 全局红色标题、仅 toast 一闪而过 |
| 结构分组 | 空间、浅分隔线 | 每组包一张重边框卡片 |

语义取值以 tokens.json 为准。预览手册从同一文件生成色板和 CSS；工作台外壳、流程、设计和元素关联已在 2026-10-16 接入同一份语义变量；业务原型内部仍使用各端的设计语言。

## typography · 字体

字体栈为 Inter（本机可用时）、系统字体、PingFang SC、Microsoft YaHei、sans-serif。无外网字体依赖，中文使用系统字形。

| 层级 | 字号 / 行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| 工具 | 12 / 20px | 400 | 菜单、按钮、属性值、表单标签 |
| 面板标题 | 13 / 20px | 500 | 属性组与面板名称 |
| 辅助 | 11 / 16px | 400 | 数量、时间、简短状态 |
| 文档正文 | 14 / 24px | 400 | 需求、规范与较长说明 |
| 文档小标题 | 18 / 28px | 500 | 阅读内容分节 |
| 文档主标题 | 28 / 36px | 600 | 独立文档顶部，不能挪进工具栏 |

### 层级的形成

标签显式指定 400，避免继承父级 600。选中优先用底色、位置和 500 字重表达；辅助文字不以继续变小代替信息取舍。连续中文长文保持舒适行距，数字表格用等宽数字。

以上尺寸为本系统中文校准值；公开资料不足以证明它们是 Figma 编辑器逐项实测值。

## geometry · 间距与形态

| 对象 | 规范 |
| --- | --- |
| 间距 | 4px 基准：4、8、12、16、24、32 |
| 图文间隔 | 8px；同组控件 4—8px |
| 面板内边距 | 12—16px；分组间隔 16—24px |
| 桌面控件 | 默认 32px 高；密集工具 28px，不能缩小点击区来容纳更多操作 |
| 触控主要操作 | 至少 44px 点击区域 |
| 圆角 | 控件 6px；分组容器 8px；浮层 12px |
| 图标 | SVG，24 × 24 viewBox，16px 显示，stroke-width=1.5（SVG 单位） |
| 层次 | 普通面板靠表面和分隔；菜单与浮层可用轻阴影 |
| 动效 | 选择立即响应；浮层 120—180ms；只声明实际属性 |

### 布局与响应

工作台侧栏按内容和最小画布宽度取舍，不把固定三栏压到手机上。收起属性栏后，当前对象的主要操作仍须可达。窄屏浮层保留标题、关闭、正文滚动和底部操作。

减少动效模式取消位移与缩放，保留必要状态反馈。长页面以真实高度展开，不能裁掉弹窗底部或缩成不可读的缩略图作为唯一预览。

## icons · 图标与间距

本章将已确认的图标实现作为统一基线。尺寸是本系统的校准值；Figma 官方资料用于借鉴组件、变量和状态的组织方法，不能据此宣称每项数值都与编辑器一致。

### 四层尺寸分别处理

| 层级 | 当前规范 | 判断方式 |
| --- | --- | --- |
| 图形坐标 | SVG viewBox 为 24 × 24 | 所有图形共用坐标系，不逐页混用字符、emoji 或图标字体 |
| 图标盒 | 16 × 16 CSS px | 宽高固定、display:block、禁止被 flex 压缩 |
| 实际图形 | 在同一盒内保留适当留白 | 按视觉重量与中心校准，不把所有形状机械拉满 |
| 点击区域 | 常规 32、画布 36、触控至少 44px | 图标盒居中，hover、选中与焦点作用于完整控件 |

32、36、44px 外框与 16px 图标盒之间，每侧分别有 8、10、14px 空间（含边框），由控件居中布局形成。不能同时给 SVG、按钮和外层重复加 padding。SVG 自身留白属于图形设计，不替代组件间距。

### 描边与视觉对齐

- 当前 stroke-width 为 1.5 个 SVG 坐标单位，round 端点和连接；24 viewBox 缩到 16px 时，描边约为 1 CSS px。保持当前实现，不把无单位参数误写成固定 1.5 CSS px。
- 图标盒在按钮内水平与垂直居中；图文按钮按整行内容对齐，长名称允许正常占位。箭头、链条等不对称形状需要调整时，修图形路径或统一组件，避免逐页用负 margin 或 transform 补偿。
- 复制、关闭、展开等含义全局一致，选中图标与未选中图标不因切换而改变外框尺寸。只读状态图标保持 16px，不伪装为可点击按钮。

### 间距由容器负责

| 情境 | 间距 | 使用方式 |
| --- | --- | --- |
| 图标加文字 | 8px | 图文按钮或字段辅助操作使用容器 gap |
| 图标加数量 | 4px | 关联数量等紧凑内容，数字不隐藏 |
| 面板与弹窗操作组 | 8px | 对齐同一控件网格，不分散写 margin |
| 深色画布工具组 | 4px，组内边距 4px | 工具点击区 36px，窄屏按需换行 |
| 不同语义组 | 12—16px 或必要分隔 | 避免把整排不同动作挤成无分组图标墙 |

### 状态和提示一起维护

默认、hover、pressed、focus-visible、selected、disabled 分别定义；hover 不冒充选中，focus 不改变布局，disabled 不绑定动作。按下态表示当次按压，selected 表示持续工具状态；展开控件用 aria-expanded 表达开合。

纯图标操作提供可访问名称，悬停与键盘聚焦提供简短动作名和实际可用快捷键；动态切换同时更新图形、名称、提示及 aria 状态。提示关闭后不抢走焦点。主要任务的文字按钮保留正常按钮形态；不能将“有对应图形”等同于“应去掉文字”。

### 新增与复用

先查 workbench-icons.js 是否已有同义图标；没有时增加到共享 SVG 注册表，再由 iconButton / iconButtons 使用。新增图标只校验受影响控件的真实尺寸、视觉中心、状态、键盘提示和窄屏点击区。当前样式已获确认时，补规范与复用规则，不借补规范批量改外观。
