# 组件

## button · 按钮

按钮表示动作，链接表示导航，披露控件表示同一对象展开。先按动作的用途、层级与使用场景选择形式，再决定用文字、图标或二者组合。主要任务按钮使用简短动词和明确对象，紧凑工具操作使用熟悉的图标；不要把“能画出图标”当作去掉按钮文字的充分条件。

### 层级与状态

| 类型 | 默认 | 悬停 / 按下 | 禁用 |
| --- | --- | --- | --- |
| 主操作 | action-primary 底，on-accent 白字 | action-hover / action-pressed | disabled 底与文字，不能执行 |
| 次操作 | surface 底、control 边框、主文字 | hover / pressed 底 | 保留形状，禁用文字 |
| 轻操作 | 透明底、主文字 | hover / pressed 底 | 不叠透明度 |
| 危险操作 | danger 文字，必要时危险实底 | 对应危险背景 | 原因可查，不能提交 |

默认 32px 高，左右 12px，12px/20px/400；主操作可 500，圆角 6px。一个操作组通常只突出一个主动作。图标按钮为 32px 点击区域、16px 图标、stroke-width=1.5（24 viewBox 的 SVG 单位）；触屏主要操作 44px。提供 aria-label，悬停和键盘聚焦显示简短操作名与必要快捷键。图标盒、点击区和间距分别按基础章节的“图标与间距”校验。

### 图标与文字的判断

- “已写／待写”这类明确状态使用带勾文档／空白文档，不再常驻文字；悬停和所在行键盘聚焦显示“需求文档已写／待写”。这类辅助信息精简不等于去掉正常按钮。
- 工具栏、画布、紧凑行内的关闭、复制、缩放、预览、设置等工具操作适合图标按钮；同一图形含义保持一致。
- 表单提交、弹窗完成／取消、关联确认、恢复版本和空状态的首次新建等，使用清晰的文字按钮，按层级保留主色、边框或轻操作样式。图标加文字在帮助辨识时可用，不强制拆除。
- 同一动作可以随场景变化：页面列表标题旁“新增”用加号，空画布的主入口用“新建页面”；弹窗右上角用关闭图标，底部用“完成”按钮。
- 操作组按对象和频率分组；不要把原来的满宽文字按钮直接变成空荡的满宽图标按钮。
- 具体需求标题、页面名称、字段标签与数量保留可读内容。业务状态和动作逐项判断：图形无法准确区分的值、保存失败的恢复选项和危险操作确认保留必要短名称与后果；不能仅因属于“状态”就默认保留文字。
- 图标状态与动作名称一起更新，重绘不得出现图标消失、含义变了但提示未变、无可访问名称等问题。

### 图标控件的统一实现

确定适合纯图标的操作后，使用 `workbench-icons.js` 的 `iconButton` / `iconButtons`。普通文字按钮保持按钮文字和原有语义，不批量调用图标转换；已经清楚的按钮名称无需再用 tooltip 重复。百分比等含内容的工具操作可使用 `controlHint`，保留内容本身。动态图标在渲染函数内同步名称、提示与状态，不另写字符图标或原生 title 提示。

| 场景 | 图标 / 点击区域 | 间距与状态 |
| --- | --- | --- |
| 侧栏、工具条、弹窗 | 16px / 32px，stroke-width=1.5 | 操作间隔 8px；普通操作透明，hover 浅灰，按下加深 |
| 深色画布工具条 | 16px / 36px | 间隔 4px；选中工具主蓝底，白图标 |
| 触屏主要操作 | 16px / 至少 44px | 允许按组换行，不挤压对象名称 |
| 关联数量 | 链条 16px / 至少 32px | 数量保留，内容与图标间隔 4px |
| 只读状态 | 16px，stroke-width=1.5；无独立按钮 | 用不同图形区分状态，使用次级色；不添加按钮背景或额外 Tab 停靠点 |
| 聚焦与禁用 | 2px 焦点框，外偏移 2px | 禁用不再叠透明度，不响应操作 |

- 常规开关 / 披露使用浅灰选中底及 `aria-pressed` / `aria-expanded`；深色画布工具使用主蓝选中，不能仅改变图形却不更新语义状态。
- 悬停约 300ms 显示简短提示，键盘聚焦立即显示；提示离开后收起，Esc 可关闭。浮层提示不能被滚动容器或原生 dialog 裁切；触屏不依赖悬停完成操作。
- 同一动作的图形固定：连线用方向连线，需求关联用链条，预览用播放，版本恢复用历史，解除关联用断链；不借用返回箭头表示同一对象收起。
- 弹窗顶部关闭使用图标；底部完成、取消、确认和保存失败的恢复选项使用文字按钮。删除 / 覆盖等危险确认明确动作与后果。
- 小屏的次要操作可在选中对象后出现；不能为了保留始终可见的重命名按钮，把流程名称挤到不可读。
- 只读状态使用共享 SVG 和 `wb-status-icon`，提供状态可访问名称与 `data-tooltip`。所在行支持操作时，使用 `data-tooltip-on-focus` 在该行键盘聚焦时解释状态，不将状态伪装成可点击按钮。

### 工具栏与属性区的细节

- 工具栏按操作用途分组，组内紧凑、组间以留白或细分隔线区分。百分比使用等宽数字，图标保持 16px，常规点击区 32px、深色画布工具 36px；触屏工具与文字操作都提高至 44px。
- 同一画布底部的工具栏与缩放栏共用布局容器，不分别占用相同的绝对定位坐标。按画布实际剩余宽度自动换行，组间保留至少 8px；极窄时工具按钮也可换行，不能靠提高层级遮住另一组。
- 悬停、选中、按下、禁用分别定义，样式优先级也需验证。已选工具悬停仍能辨认选中状态；普通工具按下不伪装成持续选中。
- 属性输入默认浅灰底、透明边框，悬停出现边框，聚焦使用白底及 2px 内侧焦点框，不改变尺寸。页面属性、元素样式、流程属性采用同一字段节奏；错误与禁用状态继续覆盖普通状态。
- 属性分区标题采用整行命中，桌面 36px、触屏 44px；右侧固定 16px chevron，展开旋转，避免原生三角和不同箭头混用。焦点框放在行内，不被滚动区域裁切。
- 属性重置按钮出现前就预留对应空间；悬停不能挤动数值或下拉箭头。面包屑保留滚动能力，键盘焦点不能被裁切。

### 行为

- 处理中保留原宽度和动作名称，可用“正在导出”；禁止重复提交。
- Tab 可聚焦，Enter/Space 可执行，focus-visible 清晰可见。
- 图标含义不确定时保留短名称；不要靠长 tooltip 教用户完成主路径。tooltip 在悬停和键盘聚焦时可见，不占用常驻布局。
- 可撤销的新增不增加确认；删除的确认按后果决定，不泛化到所有按钮。

## input · 字段与表单

标签 12px/20px/400、次级文字；输入值主文字。默认 32px 高、6px 圆角、左右 8px，输入组间隔 12px。多行文本按内容提高高度。

| 状态 | 呈现与动作 |
| --- | --- |
| 空值 | 有稳定标签；placeholder 只给示例，不能代替标签 |
| 聚焦 | 2px focus；不改变布局尺寸 |
| 编辑 | 保留输入和光标，中文组合输入结束后再提交 |
| 校验失败 | 贴近字段给出原因和修复方法，关联 aria-describedby |
| 只读 | 内容仍可选择与复制，不伪装成禁用空框 |
| 禁用 | 确实不可操作；条件依赖贴近相关字段 |

### 保存

工作台属性和备注采用自动保存。普通字段失焦不跳出弹窗；未完成的输入保留草稿。新增空白草稿允许取消，已有内容不能被错误静默清空。服务端失败或版本冲突保留本地输入，明确重试或比较入口。

## navigation · 导航与披露

名称、分组和选中状态共同表达位置。仅在需要辨别时显示数量、来源和状态。

| 对象 | 规则 |
| --- | --- |
| 顶部页签 | 名称简短；同级使用一种选中样式；不附逐项说明 |
| 左侧列表 | hover 与 selected 有区别，选中项仍使用主文字 |
| 展开 / 收起 | 同一控件原位切换，右向 / 下向 chevron，aria-expanded |
| 返回来源 | 保留来源对象与位置；可使用返回语义，但不能替代展开控件 |
| 状态选择器 | 显示真实状态名；选择后在当前任务内切换 |

### 画布树列表的行细节

适用于需求工作台的页面/状态树，以及明确沿用相同操作语义的树列表；不是对所有列表和按钮圆角的全局改动。

- 以完整逻辑行承载悬停、按下、选中与键盘焦点。分组的披露箭头与名称共享整行背景，不能各自生成圆角按钮底。
- 密集画布树采用平直行边缘。连续多选使用相同起点、宽度和背景，不逐行添加圆角形成接缝；间隔选中保留未选中行，不用大背景跨过它们。
- 缩进只作用于行内内容，不缩短选中背景；图标列、名称列、数量列固定。名称截断、数字变化、选中和重命名不能推动相邻列。
- 箭头使用共享 SVG，在固定图标盒中旋转右向/下向；点击区域桌面 32px、触控 44px，展开本身不代表选中。hover 不盖掉 selected，focus 用行内描边避免被滚动区裁掉。
- 折叠后保持触发位置与键盘焦点，切换不改变选中页面。方向键按逻辑行移动，不能将同一行的箭头与名称算成两个上下停靠点；左右用于进入/离开层级或展开/收起。
- 搜索时先展开匹配结果，但箭头仍能折叠；搜索中的开合状态不覆盖普通列表的开合状态。可访问名称、提示、箭头方向与真实显示内容保持一致。
- 以上是工作台的实现规范与中文界面校准，不作为 Figma 编辑器逐像素测量值。验证单选、相邻/间隔多选、整组选中、折叠、鼠标与键盘焦点、窄屏和长名称。

### 焦点与查找

重绘后保留键盘焦点。新增对象即使在筛选中也应可见。菜单关闭回到入口；Escape 先关闭当前最内层浮层。列表内容过长允许搜索，查不到时给出真实空结果。

### 需求目录侧栏

- 需求目录沿用画布树的平直整行状态。模块行桌面 32px，含真实 Gitee 状态的需求行 56px；触屏逻辑行至少 44px。名称、箭头、数量和文档状态使用固定列，选中不加粗造成截断位置变化。
- 名称截断时才提供完整名称提示；真实 Gitee 编号/状态和需求文档已写/待写标识保留。归档按钮预留空间，悬停与聚焦不挤动标题；行内焦点不被滚动容器裁切。
- 上下键按逻辑行移动，左右键展开/收起或回到模块，Home/End 定位首末行；Enter/Space 保留按钮本身的动作。搜索中的折叠独立于普通目录，清除搜索恢复原列表位置。
- 同一导航只保留必要开关：需求目录不再提供独立“收窄/恢复宽度”按钮，设计区继续使用其现有“显示/隐藏需求目录”入口。归档、模块折叠与真实内容不因精简按钮改变。

## panel · 面板与浮层

侧栏承担持续属性编辑；popover 承担局部轻量选择；dialog 用于需要集中处理的完整任务。先选合适容器，再决定是否需要遮罩。

### 结构

标题只表达一次。保存状态放在固定且相关的位置。分组用间距和浅分隔线，必要规则贴近操作；内部实现和设计理由留在文档。

### 关闭与恢复

常规表单弹窗使用 20px 内容内边距，标题与关闭按钮垂直居中，标题行后留 16px，底部操作前留 24px、操作间隔 8px。标题 13px/20px/500，字段和动作 12px/20px。长列表弹窗保持标题和关闭入口可达。预览弹窗按实际标题栏高度分配剩余内容高度；工具按组换行，不能写死内容高度扣减而遮挡预览。关闭、取消和预览返回沿用原有焦点及上下文恢复逻辑。

弹窗有可访问名称、明显关闭入口、焦点约束，关闭后回到触发控件。点击外部不能导致未保存内容丢失。小屏保留正文滚动，避免关闭按钮和最终操作超出视口。

### 上下文属性

没有选中对象时显示适用空状态；选中页面、状态、节点时显示对应属性。状态画板是派生视图，不能呈现不可编辑的坐标、尺寸作为可修改表单。

## feedback · 反馈与空状态

| 情况 | 反馈 |
| --- | --- |
| 保存中 | 固定位置显示正在保存，避免工具栏跳动 |
| 已保存 | 使用清晰的完成图标及按需短提示，不重复弹成功 toast |
| 保存失败 | 保留输入、错误原因和重试入口；状态不能误报已保存 |
| 内容冲突 | 保留双方版本；允许比较与选择，不自动覆盖 |
| 首次空 | 简短说明缺少什么，并提供一个可执行入口 |
| 搜索无结果 | 保留搜索词，支持修改或清除条件 |
| 无权限 | 解释实际限制，并提供合理的返回或申请路径 |

loading、空数据和错误是不同状态。缺失值显示“--”，不能当作 0。反馈不能遮挡正在编辑的字段。操作状态使用 aria-live，避免每次输入都播报冗长消息。
